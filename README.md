
# Inventory Management Backend

Backend service สำหรับระบบจัดการสินค้า (Products, Categories)
พัฒนาโดยใช้ Node.js, Express, MongoDB

# Tech Stack
- Node.js

- Express.js

- MongoDB (Mongoose)

- RESTful API

# Installation

- git clone git@github-hsac:Nakarin-k-hsac/inventory-service.git
cd inventory-service
- npm i
- npm run dev
